# Benchmark Results

The results of the benchmarks in `bench/`: every PEGO backend (closure, recursive and iterative bytecode VMs, Go
parsers generated by `pego gen`) and, where a comparable parser exists, the Go standard library. What the benchmarks
measure, the analysis of these results, and the history of the optimizations behind them are in
[performance.md](performance.md).

This file is generated: `go run ./bench/report` runs the benchmarks, measures the generated TypeScript parsers and
the sizes of the generated parsers, saves the raw results to [`bench/results.txt`](../bench/results.txt),
[`bench/results-ts.txt`](../bench/results-ts.txt) and [`bench/results-size.txt`](../bench/results-size.txt)
and writes this file from them; `go run ./bench/report -in bench/results.txt` rewrites it from saved results. Do not
edit it by hand: a test checks that it matches the results.

## Run

Measured on 2026-10-29 at commit 13b3d186 with go1.27.1 on Apple M3 Max (darwin/arm64, 16 cores), with a load average of 3.54 3.98 4.39 (1, 5 and 15 minutes) when the run started.
Times and memory are per operation, the median of 3 runs. Factors in parentheses are relative to the closure backend (lower is faster), except where a table says otherwise.
The generated TypeScript parsers were measured with Node v24.13.0.

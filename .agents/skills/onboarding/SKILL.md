# ZeroParse Development Onboarding

Before changing code or documentation, identify the requested scope and inspect the live
checkout (`pwd`, branch, worktree status and relevant files). This skill is a route to
maintained sources, not a snapshot of their current state. Follow `AGENTS.md` and the
task's authorization boundaries.

- For where a change belongs and which source is authoritative, read
  [repository map](references/repository-map.md).
- For language or runtime behavior, cross-backend correctness, and design status,
  read [contracts and correctness](references/contracts-and-correctness.md).
- For selecting checks, measurement and integration evidence, read
  [verification and integration](references/verification-and-integration.md).

Load only the references relevant to the task. Consult the linked project documents
and specialized skills at the point of use; verify current backlog and Git state live.

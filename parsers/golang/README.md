# Go

`github.com/ornew/pego/parsers/golang` parses Go source files as `go/parser` parses them, with a parser generated by
PEGO from [golang.pego](golang.pego). It depends only on the standard library.

```bash
go get github.com/ornew/pego/parsers/golang
```

## Use

```go
// A go/ast tree, as go/parser.ParseFile(fset, "x.go", src, parser.SkipObjectResolution) returns it.
fset := token.NewFileSet()
f, err := golang.ParseFile(fset, "x.go", src, 0)

// Typed values modeled on go/ast, with positions in bytes.
file, err := golang.ParseAST(string(src), golang.Bytes)
```
